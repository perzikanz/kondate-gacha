# 献立ガチャ

週7日分の夕食献立をランダムに決めるWebアプリ。

**デモ**: https://kondate-gacha.vercel.app/

## 技術スタック

- Next.js (App Router) / TypeScript
- Tailwind CSS
- Vercel（ホスティング）

## ローカル開発

```bash
git clone https://github.com/perzikanz/kondate-gacha.git
cd kondate-gacha
npm install
npm run dev
```
